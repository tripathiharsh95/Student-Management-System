# Student Management System

A simple console-based Student Management System built using Java. This project is designed for beginners to understand Java fundamentals, Object-Oriented Programming, and CRUD operations.

## Features

* Add student details
* View all students
* Search student by ID
* Update student information
* Delete student record
* Console-based menu system

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* Scanner
* Loops and Conditions
* CRUD Operations

## Project Structure

```bash
Student-Management-System/
│
├── Student.java
├── Main.java
└── README.md
```

## How to Run

Compile the Java files:

```bash
javac Student.java Main.java
```

Run the project:

```bash
java Main
```
